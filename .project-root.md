```

├── mobile-app/              # React Native iOS/Android app
├── backend/                 # Node.js Express API server
├── aws/                     # AWS infrastructure (Terraform)
├── testing/                 # Test suites (unit, integration, e2e)
├── models/                  # TensorFlow Lite models

├── docs/                    # Documentation
├── .github/                 # GitHub Actions CI/CD
├── README.md                # Project overview
├── setup.md                 # Setup instructions
```

## Quick Start

```bash
# Setup development environment
bash scripts/setup-dev.sh

# Run mobile app
cd mobile-app && npm run android

# Run backend server
cd backend && npm run dev

# Deploy AWS infrastructure
cd aws/terraform && ./deploy.sh
```

## Key Technologies

- **Frontend**: React Native, TypeScript, TensorFlow Lite
- **Backend**: Express.js, Node.js, AWS SDK
- **Database**: SQLite (local), DynamoDB (cloud)
- **Security**: AES-256 encryption, JWT, Keystore
- **Infrastructure**: Terraform, AWS (API Gateway, Lambda)
